# 🚲 VELO — Smart Campus Mobility Platform

> **My flagship backend/product engineering project**

VELO is a campus mobility platform designed for bicycle rentals inside universities.

The project focuses on solving real-world problems around authentication, student verification, booking, payments, wallet management, ride sessions, administration, and scalable backend architecture.

### 🔐 Authentication & Security

- Google Authentication
- JWT Authentication
- Spring Security
- Role-Based Access Control
- Student ID Verification
- Secure REST APIs
- Global Exception Handling

### 🚲 Mobility & Booking

- Bicycle Management
- Booking System
- Ride Sessions
- Ride Duration Tracking
- Booking Status Management
- Ride History
- QR-Based Booking
- Rider Dashboard
- Admin Dashboard

### 💳 Payments & Wallet

- Razorpay Integration
- Wallet-Based Payment System
- Wallet Top-Up
- Booking Payment Processing
- Dynamic Pricing
- Payment State Handling
