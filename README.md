VELO is a campus mobility platform designed to simplify bicycle rentals inside universities.

The project focuses on solving real-world problems around authentication, student verification, booking, rides, payments, wallets, administration and campus mobility.

### ■ Authentication & Security

- Google Authentication
- JWT Authentication
- Spring Security
- Role-Based Access Control
- Student ID Verification
- Secure REST APIs
- Global Exception Handling

### ■ Mobility & Booking

- Booking Status Management

- Admin Dashboard

### ■ Payments & Wallet
